# 💾 Sauvegarder l'image de carte

## Étapes rapides

### 1. Sauvegarde l'image que tu as envoyée

**Sur Mac** :
1. Clique-droit sur l'image dans le chat
2. "Enregistrer l'image sous..."
3. Nomme-la : `map-background.png`
4. Sauvegarde-la dans : `/Users/idriss.ouazzani/Cursor/Corail-mobileapp/assets/`

**Chemin complet** :
```
/Users/idriss.ouazzani/Cursor/Corail-mobileapp/assets/map-background.png
```

### 2. Ou télécharge une image similaire

Si tu n'as plus l'image, télécharge-en une sur :
- https://www.shutterstock.com/image-vector/city-map-pattern-seamless-black-white-1323573650
- Recherche Google : "city map pattern black white"

## Alternative rapide : utilise curl

```bash
cd /Users/idriss.ouazzani/Cursor/Corail-mobileapp/assets
```
