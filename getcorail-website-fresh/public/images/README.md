# Images de la landing Corail

Placez vos fichiers ici. Les noms doivent correspondre exactement à ceux ci-dessous pour que le site les affiche.

## Screenshots app (section « L'application » / « Un portail, deux côtés »)

| Fichier à déposer | Utilisation | Format conseillé |
|-------------------|-------------|------------------|
| **app-factures.jpeg** | Premier téléphone (factures) | JPEG, ratio type téléphone (ex. 9:19.5), min. 220px de large |
| **app-outils.jpeg** | Deuxième téléphone (outils) | Idem |

Affichage : largeur 220px, hauteur auto, coins arrondis type smartphone. Vous pouvez fournir des images plus grandes (ex. 440×900 px), Next.js les servira correctement.

## Badges App Store / Google Play (section CTA)

| Fichier | Utilisation |
|---------|-------------|
| **app-store-badge.png** | Badge « Télécharger sur l'App Store ». |
| **play-store-badge.png** | Badge « Disponible sur Google Play ». |

Format officiel : Apple fournit des SVG sur [App Store Marketing Guidelines](https://developer.apple.com/app-store/marketing/guidelines/). Google fournit des visuels sur [Google Play Badges](https://play.google.com/intl/en_us/badges).
