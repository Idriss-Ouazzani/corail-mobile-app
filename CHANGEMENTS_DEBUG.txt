PROBLÈMES POSSIBLES :
--------------------

A. currentUserId n'est pas défini
   → Vérifier les logs de setUserId
   → Redémarrer complètement l'app

B. Politiques RLS trop restrictives
   → Exécuter 010_debug_quotes_rls.sql
   → Vérifier que la politique "quotes_all_access_policy" existe

C. driver_id ≠ User ID
   → Vérifier dans Supabase Table Editor
   → Comparer avec les logs

D. Format de réponse incorrect
   → Devrait être { data: [...], error: null }
   → Vérifier les logs "📦 Réponse listQuotes:"

E. Les devis ne sont pas créés du tout
   → Vérifier Table Editor > quotes
   → Si vide, problème lors de l'insertion
